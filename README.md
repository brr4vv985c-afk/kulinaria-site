# «А ещё есть?» — сайт домашней кулинарии

Одностраничный сайт: Балашиха, мкр. Новое Павлино, ЖК Новоград Павлино, корпус 31.

Адрес сайта: **https://brr4vv985c-afk.github.io/kulinaria-site/**

## Как поменять меню и цены

Всё меню лежит в файле `menu.json`. Откройте его на GitHub, нажмите на карандаш (Edit), поменяйте и нажмите **Commit changes** — через минуту-две сайт обновится.

Одно блюдо выглядит так:

```json
{ "name": "Оливье", "price": 280, "weight": "300 г", "description": "Классический", "photo": "images/olivie.jpg" }
```

- `price` — только число, без «₽».
- `description` можно оставить пустым: `""`.
- Чтобы временно скрыть блюдо, добавьте `"available": false`.
- Новая категория — ещё один блок в `categories` со своими `id` (латиницей, без пробелов), `title` и `items`.
- Следите за запятыми между блюдами — после последнего блюда в списке запятой нет.

## Как добавить фото

1. Загрузите фото в папку `images` (Add file → Upload files). Лучше квадратное, около 800×800, в формате JPG, до 200 КБ.
2. В `menu.json` у блюда пропишите `"photo": "images/имя-файла.jpg"`.

Если фото нет или имя написано с ошибкой, покажется заглушка `images/placeholder.svg`.

## Что заменить на свои данные

Сейчас стоят примеры. Найдите и замените во всех файлах (`index.html`, `js/main.js`):

| Что | Пример сейчас | Где |
|---|---|---|
| Телефон для ссылок | `+79000000000` | `index.html`, `js/main.js` |
| Телефон для показа | `+7 900 000-00-00` | `index.html`, `js/main.js` |
| WhatsApp | `wa.me/79000000000` (номер без «+») | `index.html` |
| Telegram | `t.me/aeshcheest` | `index.html` (в двух местах + в `sameAs` микроразметки) |
| Часы работы | `9:00–21:00` | `index.html` (текст + `openingHoursSpecification`) |
| Условия доставки | блок «Доставка» | `index.html` |

## Яндекс.Метрика (для Директа)

1. Создайте счётчик на https://metrika.yandex.ru, адрес сайта — как выше. Включите «Вебвизор».
2. Скопируйте код счётчика и вставьте в `index.html` между строками
   `<!-- Яндекс.Метрика: вставьте сюда ... -->` и `<!-- /Яндекс.Метрика -->`.
3. В `js/main.js` впишите номер счётчика: `var METRIKA_ID = 12345678;`
4. В Метрике создайте цели типа «JavaScript-событие» с идентификаторами:
   `call` (звонок), `telegram`, `whatsapp`, `order_open` (нажали «Заказать»).
   Их можно использовать как конверсии в Яндекс Директе.

## Яндекс.Вебмастер

Добавьте сайт в https://webmaster.yandex.ru, выберите подтверждение через мета-тег и вставьте его в `index.html` вместо закомментированной строки `yandex-verification`. Карта сайта: `…/kulinaria-site/sitemap.xml`.

Также стоит добавить организацию в Яндекс Бизнес (карточка на Картах) и указать там ссылку на сайт.

## Публикация

Сайт публикуется автоматически (GitHub Actions, `.github/workflows/pages.yml`) при каждом изменении в ветке `main`.
Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

## Проверить у себя на компьютере

Меню загружается из `menu.json`, поэтому при открытии `index.html` двойным кликом оно не покажется. Запустите в папке сайта `python3 -m http.server` и откройте http://localhost:8000.
